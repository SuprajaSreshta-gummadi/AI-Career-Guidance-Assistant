## Project Overview

The AI Career Guidance Assistant is a Python-based conversational chatbot that helps students explore career paths, understand required skills, learn about industry trends, and receive career recommendations.

## Features

- Greeting and Introduction
- Career Path Exploration
- Skill Requirement Analysis
- Industry Trends Insights
- Profile-Based Recommendations
- Career Guidance
- Salary Insights
- Interview Preparation Tips
- Career Goal Setting

## Technologies Used

- Python
- NLTK
- Scikit-learn
- TF-IDF Vectorizer
- Logistic Regression
- JSON
